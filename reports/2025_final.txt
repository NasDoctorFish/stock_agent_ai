# 🚨 **핵심 문제: `tf-keras` 라는 패키지는 존재하지 않음**

Poetry가 말하는 에러:

```
tf-keras (2.14.0) which doesn't match any versions, version solving failed.
```

이 말은:

✔ **PyPI에 tf-keras==2.14.0 버전이 없다**
✔ 사실 거의 모든 버전이 없다
✔ “tf-keras”라는 패키지는 TensorFlow 공식 패키지가 아님
✔ TensorFlow와 함께 설치되는 내부 모듈일 뿐, pip 패키지로 존재하지 않는다

즉,

# ❌ **`tf-keras`는 pip 설치가 필요 없다 → 아예 제거해야 한다**

TensorFlow 설치하면 자동으로 포함됨.

---

# 🧠 왜 처음에 tf-keras를 요구하게 됐나?

TensorFlow 2.20부터 내부 구조가 변해서, 일부 문서나 유튜브에서 “tf-keras” 별도 패키지처럼 언급했지만:

* 이것은 PyPI의 실제 배포 패키지가 아님
* pip로 설치할 수 없음
* Poetry의 version solver가 이 패키지를 찾지 못해 실패함

결과 = **한 개의 잘못된 패키지가 전체 종속성 해결을 망침**

---

# ⭐ 해결방법 (아주 간단함)

그냥 pyproject.toml에서 **tf-keras 줄을 완전히 삭제**하면 됨.

TensorFlow만 남겨두면 TensorFlow 내부에서 자동으로 Keras가 로딩됨:

### TensorFlow 2.14

* keras 포함
* tf.keras 사용 가능

---

# ✔ 수정된 pyproject.toml (핵심 문제 제거 버전)

```toml
tensorflow = "2.14.0"
# tf-keras 제거함
protobuf = "4.25.3"
pyarrow = "14.0.2"
```

이제 다른 패키지는 문제 없음.

---

# ⚙️ 이후 해야 할 것

```
rm poetry.lock
poetry lock
poetry install
```
