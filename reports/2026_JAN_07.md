# Context
현재 Python 프로젝트에서 DART(OpenDART) 공시 데이터를 수집하고 있다.
df_filings는 pandas DataFrame이며 corp_code / rcept_no / reprt_code는 정상적으로 수집되었으나,
dcm_no 컬럼은 비어 있거나 존재하지 않는다.

viewer.do 기반 본문 접근(fetch_viewer_body)은 rcept_no + dcm_no를 필요로 하지만,
현재 dcm_no가 없어 기존 접근 방식이 실패할 가능성이 높다.

# Problem
- df_filings에 dcm_no가 없어 viewer.do 접근이 제한된다.
- document.xml API는 신뢰할 수 없으며 HTML(EUC-KR)로 반환되는 경우가 많다.
- 그럼에도 불구하고 corp_codes에 포함된 기업들의 공시 본문을 반드시 수집해야 한다.

# Mandatory Goals (반드시 해결)
1. corp_codes에 포함된 기업들의 공시 자료를 기반으로,
   DART 웹(viewer.do 또는 동등한 HTML 엔드포인트)을 활용하여
   공시 본문(raw text)을 직접 스크래핑한다.
2. dcm_no가 없는 상황을 고려하여,
   viewer.do 접근을 위한 우회 전략을 설계 및 구현한다.
   (URL 패턴 분석, iframe/JS 기반 접근, main.do → viewer.do 직접 접근 등 허용)
3. 수집한 본문 데이터를 DuckDB에 저장한다.

# LLM Processing Requirements
- 로컬 LLM 모델(qwen2.5-1.5b)을 사용한다.
- 각 공시 본문에 대해 다음 분석을 수행한다:
  1) 중요도(Importance Level) 분류
  2) 공시 성격 카테고리 태깅
  3) 요약 생성

# Importance Level Classification (핵심 요구사항)
각 공시는 반드시 아래 중 **하나의 Importance Level**로 분류해야 한다.

- IMP (Important – Revenue Critical)
  정의:
  - 매출, 영업이익, 순이익에 직접적인 영향을 주는 공시
  - 신규 수주, 대형 계약, 실적 급변, 핵심 사업 투자
  - 향후 수익 창출 가능성이 명확한 내용
  예시:
  - 대규모 공급 계약 체결
  - 분기/연간 실적 서프라이즈
  - 신규 사업 본격화, CAPEX 투자

- NORMAL (Relevant but Not Revenue-Critical)
  정의:
  - 기업 운영, 구조, 전략상 의미는 있으나
    단기적 수익 영향은 제한적인 공시
  예시:
  - 조직 개편
  - 일부 지분 변동
  - 중소 규모 투자, 일반 공시

- NOT_IMPORTANT (Noise / Compliance)
  정의:
  - 형식적, 의무적, 반복적 공시
  - 투자 판단 및 수익 창출과 거의 무관
  예시:
  - 단순 정정 공시
  - 감사보고서 제출 안내
  - 내부 규정 변경

⚠️ 반드시 IMP / NORMAL / NOT_IMPORTANT 중 하나만 선택할 것.

# Category Tagging Requirements
각 공시에 대해 아래 카테고리 중 복수 선택 가능:

- earnings
- investment
- contract
- risk
- governance
- restructuring
- compliance
- other

# Data Storage Specification (DB 저장 규칙)
각 공시 문서는 다음 컬럼 구조로 저장한다:

- corp_code
- rcept_no
- reprt_code
- importance_level  (IMP / NORMAL / NOT_IMPORTANT)
- tags              (JSON or list)
- title_summary     (한 줄 요약)
- paragraph_summary (문단 요약)
- raw_text          (정제된 전체 본문)

# Output Requirements
- Python 코드로 구현한다.
- 기존 df_filings 파이프라인과 자연스럽게 연결되도록 한다.
- EUC-KR 인코딩과 HTML 파싱을 고려한다.
- DuckDB 테이블 생성 및 INSERT 로직을 포함한다.
- 핵심 로직 위주로 간결하고 명확한 주석을 작성한다.

# Additional Instruction
이 시스템의 최종 목적은
"향후 실제 수익 창출 가능성이 높은 기업 및 공시만 빠르게 선별하여 확인하는 것"이다.
따라서 Importance Level 분류 정확도를 최우선으로 고려한다.
