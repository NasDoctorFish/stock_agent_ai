Setup Steps for 24/7 Operation
1. Add to .env:


TELEGRAM_CHAT_ID=<your numeric Telegram chat ID>
# Get it: visit https://api.telegram.org/bot<TOKEN>/getUpdates after messaging your bot
2. Install APScheduler (optional but recommended):


pip install apscheduler
3. Start the daemon:


cd /Users/jju/Documents/Stock_ML
python src/main.py --daemon
Or for a one-shot run:


python src/main.py           # US + KR
python src/main.py --kr-only # Korean morning check
python src/main.py --us-only # US market check
Assumptions & Limitations
No US stock broker yet — US signals are generated but orders are not placed. Add an Interactive Brokers or Alpaca broker to src/brokers/ to complete the loop.
Coinone requires HMAC-SHA512 signing — implement _sign_request() in coinone_broker.py once you have API credentials.
Kiwoom order TR codes — kt00018/kt00019 (balance/positions) need verification against the official docs at https://openapi.kiwoom.com/guide/apiguide since exact TR names vary.
TELEGRAM_CHAT_ID must be added to .env before reports will send (messages fall back to logs/telegram_fallback.log if missing).
VKOSPI (^VKOSPI) may not be available on all yfinance versions — the KR regime detector falls back to realized KOSPI volatility rank automatically.
FRED data for KR yields (IRLTLT01KRM156N, IRSTCI01KRM156N) is monthly; the KR regime signals using these will update slowly but remain valid for medium-term regime classification.
